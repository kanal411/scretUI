# scretUI
A 3D-printed smartphone case with a 4.2" e-ink display for Samsung Galaxy A55 5G.  
The display refreshes every 5 minutes and shows time, weather forecast, to-do list, date, battery percentage, and a simplified sky visualization based on current conditions.

![Front view](images/backside.jpg)

Used parts:
-waveshare 13353
-xiao seed esp32 s3
-100k ohm resistor
-220k ohm resistor
-1500mAh 3.7V Li-Pol battery (50x34x8mm)
-9x8x8mm button

Battery housing printed with petg, case printed in TPU 90a.
